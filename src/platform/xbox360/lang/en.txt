# HarissaDC - menu texts, English (the reference: every language has the same keys).
#
# One text per line: KEY = text. "\n" starts a new line. %d, %u (numbers) and %s
# (a word or a name) are filled in by the emulator: keep each of them, in the
# same order. Button prompts ("A:Select|B:Back") are button:label pairs
# separated by "|": translate only the labels, never the buttons, and never put
# ":" or "|" in a label. Keep texts about as short as the English ones: the
# menus have fixed widths (tools/gen_lang.py checks them).
#
# After a change: python src/platform/xbox360/tools/gen_lang.py (writes xb_lang_table.h).
